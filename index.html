Limits

A limit describes the value a function approaches, whether or not the function actually reaches it. Try direct substitution first. If you get 0/0, factor, rationalize or use L'Hôpital's rule.

Worked example

limx→2 (x² − 4) / (x − 2)

  1. Substituting gives 0/0, so factor the top: (x − 2)(x + 2) / (x − 2).
  2. Cancel the common factor to leave x + 2.
  3. Substitute again: 2 + 2 = 4.
Limits worth memorizing
limx→0 sin(x) / x1
limx→0 (1 − cos x) / x0
limx→∞ (1 + 1/x)xe

Derivatives

The derivative gives the instantaneous rate of change, which is the slope of the tangent line at a point.

Core rules
RuleFormula
Powerd/dx [xⁿ] = n·xⁿ⁻¹
Product(fg)′ = f′g + fg′
Quotient(f/g)′ = (f′g − fg′) / g²
Chain[f(g(x))]′ = f′(g(x))·g′(x)
Exponentiald/dx [eˣ] = eˣ
Natural logd/dx [ln x] = 1/x
Sined/dx [sin x] = cos x
Cosined/dx [cos x] = −sin x

Worked example: chain rule

y = (3x² + 1)⁵

  1. Outer function: u⁵, whose derivative is 5u⁴.
  2. Inner function: u = 3x² + 1, whose derivative is 6x.
  3. Multiply: y′ = 5(3x² + 1)⁴ · 6x = 30x(3x² + 1)⁴.

Integrals

Integration reverses differentiation and measures accumulated area under a curve. Add + C to every indefinite integral.

Common antiderivatives
∫ xⁿ dxxⁿ⁺¹ / (n + 1) + C, n ≠ −1
∫ 1/x dxln|x| + C
∫ eˣ dxeˣ + C
∫ sin x dx−cos x + C
∫ cos x dxsin x + C

Worked example: u-substitution

∫ 2x·cos(x²) dx

  1. Let u = x², so du = 2x dx.
  2. The integral becomes ∫ cos u du = sin u + C.
  3. Substitute back: sin(x²) + C.

Fundamental Theorem of Calculus: ∫ab f(x) dx = F(b) − F(a), where F is any antiderivative of f.

Work each one on paper before opening the answer.

limx→3 (x² − 9) / (x − 3)

Factor to (x − 3)(x + 3) / (x − 3), cancel, and substitute: 6.

d/dx [x²·sin x]

Product rule: 2x·sin x + x²·cos x.

d/dx [e^(4x)]

Chain rule with inner derivative 4: 4e^(4x).
